# Tokenmetry v0.6.0

**跨设备同步与排行榜（均为显式 opt-in）、一批采集侧性能与正确性修复；外加 `grain` 之上的设备维度。**

## 这一版有什么

**跨设备同步（显式 opt-in，默认关）**

- 多台机器的聚合事实可以并进一个账号视图：设备维度进 `usage_facts` / `session_facts` 主键（迁移 3，
  旧数据回填本机 id，零手工迁移），查询面按设备过滤，顶栏在同步开启时出现设备筛选。
- 同步引擎走增量 push/pull：行级 LWW、账号级单调 `seq`、pull 快照一致（游标不越过读到上界之后的新行）、
  设备清单对账与本地清退（别的设备解绑/删号不会在你这里留残行）。
- 两条通道：**自建中继**（自己跑一个 docker 容器，一条 `docker run`，见
  [`docs/selfhost.md`](../../selfhost.md)）与**官方实例**。官方实例的 OAuth Client Id 与中继地址在
  本版为编译期占位且未填——**发行包里的官方入口不可用**，要点同步请自建中继（见「已知限制」）。
- 关闭同步 = 零出站请求；开启后过线的只有聚合事实与设备元数据，不传 prompt、代码、会话内容。

**社区排行榜（再单独 opt-in 一次）**

- 账号可选择性上榜：月度 Token 榜与金额榜并列，展示名可改，随时关榜（关榜即清名）。
- 服务端 rollup 按账号×日重算兜底，公开读端点匿名可访问；客户端设置页有开关、展示名与网页入口。
- **排行榜网页与官方榜单本版未上线**（`tokenmetry.app/leaderboard` 尚未发布）：当前数据只在自建中继
  自己的库里，见「已知限制」。

**采集：更少的重复读取**

- **ZCode**：文件指纹快路径 + 持久只读连接——空闲轮连 SQL 探针都不发（修复前空闲轮 p50 1.4 s、最坏 63 s，
  生产日志 5,087 轮回填取证）。
- **OpenCode**：两级探针（`-wal` 指纹 → `session_message` 行集），写端活跃期 `-wal` 变了但行集没变时
  不再全库重读。
- **文件型六源**（Cindy / pi-agent / Amp / Codebuff / Droid / Gemini CLI）：逐文件记账，一个会话文件变化
  不再让整批重读。
- **Antigravity**：指纹补上 `-wal` 边车——写端活跃期不再读到 checkpoint 前的陈旧账。
- **OpenCode `claude-agent` 跨源去重**：同一批用量不再被两个来源各计一次。

**修复**

- Windows 深色标题栏在重启后变白（D-026）；分享海报与模型计价器窗口补上同样的深色标题栏处理。
- ZCode 探针在"部分读取轮 × 删库"序列下的准入漏洞：记忆改全或无落账，堵住用残行继续服务零变更缓存。
- 中继侧：pull 快照一致、token 轮换退役旧账号、解绑粘滞到行摄取、畸形载荷 400 化（不再冒 500）。
- **Windows 上 `dotnet test` 全绿**：修掉一批只在 Windows 暴露的文件共享冲突（日志读取与临时库收尾），
  工具侧 `SmokeScan` 的同一处崩溃一并修掉。

**计价**

- Codex `ultrafast` 档位计价，倍率照抄 ccusage 20.0.48。

**工具与发布**

- `tools/Tokenmetry.SmokeScan` 每轮报进程级 `read_bytes` / `read_ops`（Windows `GetProcessIoCounters`、
  Linux `/proc/self/io`，macOS 记 `n/a`）——"这一轮到底从盘上读了多少"变成一条命令。
- 官网直链固定名副本：release 额外上传无版本号资产，供 tokenmetry.app 直接下载。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。本版要紧的三条：

- **官方同步通道与排行榜网页未上线**：发行包里「官方实例」入口不会成功（编译期 OAuth / 中继地址未填），
  排行榜网页 404。要跨设备同步请自建中继；排行榜数据只存在于你的自建中继里。
- **包都未签名**：Windows 安装器触发 SmartScreen「未知发布者」（→「更多信息」→「仍要运行」）；
  macOS 是 ad-hoc 签名，**全新安装**首次打开会被 Gatekeeper 拦一次（应用内更新不触发）。
  macOS 26 已没有「右键 → 打开」捷径，最省事的是终端一行：

  ```bash
  xattr -cr /Applications/Tokenmetry.app
  ```

- **Linux 版仍是单文件 R2R**（AOT 未真机验证）；**读失败仍可能被逐文件跳过**，数据页能看到「部分读取」
  但不保证每个 `IOException` 都有计数。

## 安装

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.6.0-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.6.0-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.6.0-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.6.0-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.6.0-linux-x64.zip` |

- **已装 v0.5.0 的用户：应用内一键更新**（主窗横幅 / 设置页「关于」/ 托盘菜单）。数据库迁移 3 在启动时
  自动执行，历史数字不受影响；想回退旧版本前请先备份数据目录。
- 全新安装：Windows 跑安装器（或解压便携 zip），macOS 解压后拖进应用程序目录（首次放行命令见上），
  Linux 解压即用。

## 数据与隐私

SQLite 只存聚合事实与配置，不存 prompt、代码、会话内容；**默认零网络**——价格目录刷新与应用内更新检查
之外不发请求。跨设备同步与排行榜是显式 opt-in 的例外：关闭即本地纯离线，开启后过线的只有聚合事实与
设备元数据，中继可读明文（不做端到端加密），所以只该指向你信任的中继。
