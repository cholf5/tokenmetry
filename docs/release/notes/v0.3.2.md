# Tokenmetry v0.3.2

**包小了一大截，启动也不再往临时目录写东西。**

## 这一版改了什么

macOS 与 Windows 安装器改用 **Native AOT** 编译，并改成"散开"形态（原生 exe + 几个原生库同目录）。
"一个文件就能跑"的单文件包保留给便携版与 Linux——两种形态各取所需，不是二选一。

| 产物 | 之前 | 现在 |
|---|---|---|
| Windows 安装器 | 49.8MB | **17.3MB** |
| macOS arm64 | 66.3MB | **23.1MB** |
| macOS x64 | 71.2MB | **24.6MB** |
| Windows 便携 zip | 70.8MB | 70.8MB（不变） |
| Linux zip | 66.4MB | 66.4MB（不变） |

顺带解决掉的真实问题：单文件包首次启动要把约 20MB 的原生库（Skia / HarfBuzz / SQLite）解到临时目录
（`%TEMP%\.net\...`），之后复用；AOT 形态完全不碰临时目录。这不只是快一点——企业策略禁写
`%TEMP%`、或清理工具把那个目录扫掉时，单文件版会启动失败，AOT 版不会。实测（macOS arm64）：
单文件冷启动 0.84s、暖启动 0.32–0.36s；AOT 没有那 0.5s 的首次开销，也没有 JIT 预热。

AOT 的取舍是**没有运行时 JIT**——任何运行时反射都会在用户机器上炸。仓库侧早已为零（反射式 JSON
全部迁到源生成，`TreatWarningsAsErrors` 下 publish 零 IL 警告），Windows 与 macOS 两平台也都实机
验过窗口、托盘与图表。

## 不变的部分

- **便携 zip 仍是单文件**：便携版的全部价值就是"一个 exe 双击就能跑"，AOT 不支持单文件，所以这条
  路保持不变。
- **Linux 仍是单文件**：AOT 版还没人在真机上验过。这一版给 Linux 加了 CI 启动冒烟（虚拟 X 下跑
  20 秒、确认进程存活与数据库建立），但画面与托盘验不了——等真机反馈再切。
- macOS / Linux 的更新方式仍是"下载 → 解压覆盖"；Windows 安装版仍是静默升级。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。这一版相关：

- **包都未签名**：Windows 安装器触发 SmartScreen「未知发布者」（→「更多信息」→「仍要运行」），
  macOS 仍是 ad-hoc 签名（首次打开被 Gatekeeper 拦一次）。
- **便携版与 Linux 仍有首次解包**（约 20MB 写临时目录）；想避开就用 Windows 安装器或 macOS 版。
- **Linux 的 AOT 未验证**，所以这一版没切。

## 安装

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.3.2-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.3.2-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.3.2-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.3.2-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.3.2-linux-x64.zip` |

已装 v0.3.1 的 Windows 用户：点「下载更新」会静默升级并自动重启，无需手动操作。

## 数据与隐私

SQLite 只存聚合事实与配置，不存 prompt、代码、会话内容；不上传、不登录、不云同步。
