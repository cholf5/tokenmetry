# Tokenmetry v0.4.0

**三个大功能：应用内一键更新（全平台）、分享海报、会话成本下钻弹层；外加一处采集卡死的性能修复。**

## 这一版有什么

**应用内一键更新（全平台）**

- **发现**：主窗顶部横幅自动唤回（托盘常驻应用不能只靠没人看的托盘菜单标题），设置页「关于」区
  与托盘菜单同步可见、同源同命令。
- **下载**：进度条就地显示；完整性三层校验——Content-Length 收满 → 载荷魔数（zip/PE）→
  **SHA-256 对账**（CI 为每个资产生成 `.sha256`）。校验不过就拒绝更新并删掉已下载的包。
- **应用**：Windows 已装副本走安装器静默升级；便携版 / macOS / Linux 由「同卷两次 rename」
  原子替换，任何一步失败自动回滚。替换前把 pendingVersion/backupPath 写进 `update-state.json`，
  重启后版本对不上会提示「上次更新未生效」并给出备份路径。
- 给老用户的实话：**这一版还得手动装一次**——v0.3.3 及更早的版本只会「下载 + 自己解压」，
  没有自动替换能力；装完这一版，之后每次更新都是一键完成。

**分享海报**

- 总览页页头新增分享按钮：按当前全局筛选查一次快照，生成一张可分享的用量海报。
- 三个选项：窗口（总览 / 单日）、主题（夜间 / 日间 / 跟随应用）、项目名雾化——截图分享不露项目名。
- 总览基底出竖版 1080 宽或横版 1800 宽（两行三列）；单日出竖版小卡（KPI + 构成 + 主要 Agent /
  模型排行）。Agent 与模型行带品牌标，趋势图标峰值。
- 出图后复制到剪贴板或存文件。

**会话成本下钻**

- 「会话」页点击任意一行 → 弹层只回答一个问题：**这个会话为什么这么贵**。
- Token 四分项精确值（输入未缓存 / 输出 / 缓存写入 / 缓存读取）+ 构成环图；缓存写入可展开
  5m/1h ephemeral 细分（仅 Claude 系日志携带）。
- 数据全部取自行点击时已加载的列表行投影，不发新查询、不重读源文件。

**采集与托盘**

- 托盘悬停 tooltip 两行摘要：产品名 + 今日 tokens / 成本 / 缓存命中（顺手修了 macOS 上
  hover 永远无数据的问题）。
- 采集诊断三项：`<数据目录>/logs/app.log` 文件日志（默认开，设置页可关 +「打开日志文件夹」）；
  数据源表进行中源置顶显示「正在处理 3,200/16,403」；采集轮挂死 30 分钟后等待方超时放弃本轮，
  不再无限排队。
- **修复**：Claude 历史量大时采集卡死在「正在初始化」——去重替换从每次全量重建索引（O(替换次数 × n)）
  改为增量更新索引；去重口径未改。
- **修复**（macOS）：点托盘即崩；弹层开着时点菜单栏空白处不收起（两处监听通道补齐）。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。重点：

- **包都未签名**：Windows 安装器触发 SmartScreen「未知发布者」（→「更多信息」→「仍要运行」）；
  macOS 仍是 ad-hoc 签名，首次打开被 Gatekeeper 拦一次。macOS 26 已没有「右键 → 打开」捷径，
  最省事的是终端一行命令（抹掉 quarantine 标，之后双击直接过）：

  ```bash
  xattr -cr /Applications/Tokenmetry.app
  ```

- **便携 zip 与 Linux 包仍有首次解包**（约 20MB 写临时目录）；想避开就用 Windows 安装器或 macOS 版。
- **Linux 版未在真机验证**（CI 有启动冒烟，画面与托盘验不了）。
- macOS 不做 .dmg（已决策）：zip 解压、拖进应用程序目录即可。
- v0.3.3 及更早版本升上来的这一次没有应用内自动替换（见上），之后才有。

## 安装

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.4.0-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.4.0-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.4.0-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.4.0-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.4.0-linux-x64.zip` |

- 已装 v0.3.1+ 的 Windows 用户（安装器安装）：应用内点「立即更新」，静默升级后自动回来。
- Windows 便携版 / macOS / Linux 老用户：本版是最后一次手动更新——下载 zip 解压覆盖旧版；
  从下一版起应用内一键完成。macOS 首次打开的放行命令见上。
- 全新安装：下载对应平台的包，Windows 跑安装器（或解压便携 zip），macOS 解压后拖进应用程序目录，
  Linux 解压即用。
