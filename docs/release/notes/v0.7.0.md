# Tokenmetry v0.7.0

**私有 Agent 插件体系落地；应用设置跨设备同步（独立 opt-in）；自建中继多成员与自带网页；主题扩充到十套画板。**

## 这一版有什么

**插件：把私有 Agent 接进来（新子系统）**

- `.tkmplugin` 包 = `plugin.json` + 图标 + C# 入口程序集与依赖（本质是 zip）。在「数据与计价 → 插件」
  里手动安装，本地校验包结构、manifest、API 版本、入口类型、图标与文件数/大小上限；校验不过给出
  可读错误，**不会留下"装了一半"的状态**。
- 每个插件由**独立的宿主进程**加载（`plugin-host/`，随三平台包与 Windows 安装器一起分发）。插件
  崩溃、卡死或超时只影响它自己那条数据源，主应用不受影响、继续保持 Native AOT。
- 插件数据接入现有采集管线，装好之后用量出现在总览、Agent、模型、项目、会话、时间与成本分析等
  页面；状态与内置源一致（未扫描 / 扫描中 / 未检出 / 部分数据 / 已连接 / 扫描失败）。
- 管理：启用 / 停用 / 卸载 / 升级。升级失败保留上一版本可用；停用与卸载**不删除已入库的历史事实**。
- 作者侧：插件 SDK、给工程师或 AI 的完整工作流（SKILL）、本地校验器（`validate` / `scan`），
  以及离线契约包 `plugin-sdk/contract`。契约包与源码的公开 API 由 CI 同步校验，漂移即失败。
- v1 边界：不新增页面、不改查询与计价口径、不能自带默认价格、只支持 C#、一个包对应一个 Agent；
  不做签名校验、allowlist 与进程沙箱（见「已知限制」）。

**应用设置跨设备同步（独立开关，默认关）**

- 同步范围只到纯偏好：主题（画板 + 明暗）、界面语言、分享海报默认值、自定义时间预设。设备级设置
  （开机自启、刷新间隔、日志开关等）与计价语义（模型目录、别名、价格覆盖）**永不过线**。
- 逐 key LWW，时间戳取服务端时钟；一台设备改 A、另一台改 B，互不覆盖。本机有未推送改动的 key
  不会被远端旧值顶掉。
- 首次同步发现两端不同时**停下并让用户三选一**：采用云端 / 保留本机 / 本机配置不同步（只关设置
  同步，用量同步与设备管理照常）——不静默覆盖任何一边。
- 拉到远端值后立即热应用：主题、语言、预设清单当场生效，设置页同步投影；中继删库重建后按新桶
  全量重推本机偏好。
- 关掉开关 = 零新增出站；打开后过线的只有这几项偏好值。

**自建中继：多成员与自带网页**

- `token add` 或 Web 管理页可给朋友 / 同事签发独立账号；吊销成员会级联清掉其同步行、设备与榜单
  记录。多成员共享一个中继，各自的数据互不可见。
- 中继自带只读 `/leaderboard` 榜单页与运营者 `/admin` 管理页；页面脚本外置为同源静态资源，
  CSP 收紧到 `script-src 'self'`，不放行内联脚本。
- 一键部署脚本：发布目录 tar 整包 ship + systemd 换装 + 两层防火墙核查，重部署保留已有令牌。
- 新增应用设置端点（中继 v1.2）；同步请求体改为显式 `Content-Length`，避免系统代理对较大
  chunked 请求体直接断连。

**主题与设置页**

- 画板扩充到十套：新增 Catppuccin、Tokyo Night、One、Ayu、Kanagawa。
- 主题选择器改为档位徽标 + 明暗模式预览卡，单档画板不再只有一枚置灰选项。
- 设置项说明改为悬停选项名本身（撤掉常驻小字与 ⓘ 图标），标签与右侧控件纵向对齐。
- 「官方实例」入口置灰并引导自建中继——官方同步通道与榜单网页仍未开放（见「已知限制」）。

**界面与采集**

- 项目统计页与总览项目排行支持右键：打开项目目录、终端、已安装应用。
- 插件 Agent 图标与会话 id 展示；插件源在采集管线中保留历史事实，记录映射兜底 null 与
  `LinesSkipped` 口径。
- 同步状态行长错误不再把动作按钮挤出面板。
- 契约包生成脚本与 CI 公开 API 同步校验（`pack-plugin-contract.sh` + `verify-contract`）。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。本版要紧的四条：

- **插件是本地第三方代码，没有签名、没有沙箱**：宿主与 Tokenmetry 同用户权限运行，插件可读写本机
  文件、访问网络，也有能力读取代码、日志、会话内容。只安装来自可信来源的包。另外插件宿主让每个
  包多出几十 MB（三平台各自带一份 self-contained 运行时），不用插件的人也会承担这份体积。
- **官方同步通道与榜单网页仍未开放**：发行包里「官方实例」入口置灰，排行榜网页 404。跨设备同步
  与设置同步都请自建中继；设置同步要求中继为 v1.2 及以上（旧中继没有 `/api/me/settings`，
  会返回 404）。
- **包都未签名**：Windows 安装器触发 SmartScreen「未知发布者」（→「更多信息」→「仍要运行」）；
  macOS 是 ad-hoc 签名，**全新安装**首次打开会被 Gatekeeper 拦一次。macOS 26 已没有「右键 → 打开」
  捷径，最省事的是终端一行：

  ```bash
  xattr -cr /Applications/Tokenmetry.app
  ```

- **Linux 版仍是单文件 R2R**（AOT 未真机验证）；**读失败仍可能被逐文件跳过**，数据页能看到「部分
  读取」但不保证每个 `IOException` 都有计数。

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.7.0-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.7.0-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.7.0-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.7.0-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.7.0-linux-x64.zip` |

- **已装 v0.6.0 的用户：应用内一键更新**（主窗横幅 / 设置页「关于」/ 托盘菜单）。新增的迁移 4 只是
  建一张本机设置同步账面表，启动时自动执行，历史数字不受影响。
- 全新安装：Windows 跑安装器（或解压便携 zip），macOS 解压后拖进应用程序目录（首次放行命令见上），
  Linux 解压即用。每个包都带 `plugin-host/`，安装后即可使用插件。

## 数据与隐私

SQLite 只存聚合事实与配置，不存 prompt、代码、会话内容；**默认零网络**——价格目录刷新与应用内更新
检查之外不发请求。跨设备同步、设置同步与排行榜都是显式 opt-in 的例外：关闭即本地纯离线，开启后
过线的只有聚合事实、设备元数据与上述几项偏好，中继可读明文（不做端到端加密），所以只该指向你
信任的中继。

插件改变的是**数据从哪来**：插件自身以与 Tokenmetry 相同的用户权限运行，有能力读取 prompt、代码与
会话内容——这条边界由插件作者与安装者的信任关系决定，应用不改自己的隐私红线。
