# Tokenmetry v0.3.1

**Windows 有了正经安装器，更新不再要手动解压。**

## 这一版的重点：Windows 安装与升级

**安装器（新增）** —— `Tokenmetry-0.3.1-win-x64-setup.exe`

- 按用户安装到 `%LOCALAPPDATA%\Programs\Tokenmetry`，**不弹 UAC**；
- 开始菜单项 + **桌面快捷方式**（默认勾选，可取消）；
- 自带卸载器，出现在「应用和功能」里；
- 卸载不动数据：`%LOCALAPPDATA%\Tokenmetry` 里的聚合库与设置保留，重装即接着用。

为什么这比 zip 重要：zip 只有裸 exe——没有卸载入口、没有开始菜单项，而自动启动登记的
`HKCU\...\Run` 指向用户随手解压的目录（下载文件夹一清理就失效）。安装器把路径固定下来，
自启动、快捷方式、升级从此都有稳定落点。

**应用内静默升级（新增）** —— Windows 安装版点「下载更新」：

1. 下载安装包（三个 CN 镜像依次兜底，完整性校验到字节数与文件头）；
2. 以 `/SILENT` 拉起安装器，旧实例自动退出并释放文件锁；
3. 安装器原地升级，装完把新版本自动拉起。

全程无向导、无 UAC、无「请先关闭程序」。便携版与 macOS / Linux 保持原行为：下载后在文件管理器里
定位，解压替换完成更新——**便携版不会被偷偷转成安装版**。

## 其它修正

- 设置页「当前版本」与「已是最新版本（vX）」改为读更新服务的比较基线，不再读静态程序集版本
  （上一版升版本号时暴露的显示不一致）。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。与这一版最相关的两条：

- **所有包都未签名**：Windows 安装器会触发 SmartScreen「未知发布者」→「更多信息」→「仍要运行」；
  macOS 仍是 ad-hoc 签名，首次打开被 Gatekeeper 拦一次。
- **v0.3.0 的 Windows 用户要手动跑一次安装器**才能进入「可静默升级」的状态（数据不受影响）。

## 安装

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.3.1-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.3.1-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.3.1-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.3.1-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.3.1-linux-x64.zip` |

macOS 解压得到 `Tokenmetry.app`（首次打开需放行一次）；Linux `chmod +x Tokenmetry` 后运行。

## 数据与隐私

SQLite 只存聚合事实与配置，不存 prompt、代码、会话内容；不上传、不登录、不云同步。
