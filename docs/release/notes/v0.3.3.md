# Tokenmetry v0.3.3

**两处界面细节修正 + README 改版。无功能变化、无数据格式变化。**

## 这一版改了什么

- **数据表行 hover 修正**：hover 底色此前挂在带竖向内边距的容器上，把行顶分隔线推进了 8px——
  鼠标移到某行时高亮带的上缘叠住分隔线、下缘悬空 8px，移过相邻行时分隔线还会相对跳 16px。
  现在分隔线贴齐行缘、内容在行内上下居中，行高不变；Agent / 模型 / 项目 / 会话与成本口径表一并修正。
- **托盘快捷信息窗 footer**：底部两个导航按钮改为等宽，并撤掉右侧按钮的蓝色强调块——两个按钮都是
  「离开弹窗去某页」的出口、无主次之分，而蓝在这张卡里已是状态灯 / 速率横幅 / 进度条的活动语义色，
  色块反而压过 KPI 主体。设置页里真正做决策的按钮（重扫、添加模型）不受影响。
- **README 改版**：默认语言改为英文，中文版迁至 [README.zh-CN.md](README.zh-CN.md)。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。重点：

- **包都未签名**：Windows 安装器触发 SmartScreen「未知发布者」（→「更多信息」→「仍要运行」）；
  macOS 仍是 ad-hoc 签名，首次打开被 Gatekeeper 拦一次。macOS 26 已没有「右键 → 打开」捷径，
  最省事的是终端一行命令（抹掉 quarantine 标，之后双击直接过）：

  ```bash
  xattr -cr /Applications/Tokenmetry.app
  ```

- **便携 zip 与 Linux 包仍有首次解包**（约 20MB 写临时目录）；想避开就用 Windows 安装器或 macOS 版。
- **Linux 版未在真机验证**（CI 有启动冒烟，画面与托盘验不了）。
- macOS 不做 .dmg（已决策）：zip 解压、拖进应用程序目录即可。

## 安装

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.3.3-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.3.3-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.3.3-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.3.3-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.3.3-linux-x64.zip` |

已装 v0.3.2 的 Windows 用户：点「下载更新」会静默升级并自动重启，无需手动操作。
macOS / Linux：下载 zip → 解压覆盖旧版。

SQLite 只存聚合事实与配置，不存 prompt、代码、会话内容；不上传、不登录、不云同步。
