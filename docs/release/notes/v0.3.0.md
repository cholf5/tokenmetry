# Tokenmetry v0.3.0

**首个公开版本。** 打开就知道 AI 编程花了多少钱、是否异常、钱花在哪——本地优先、托盘常驻、成本可与
`ccusage` 逐日逐模型对账。

## 这一版有什么

**19 个 Agent 数据源，零配置只读直读**
Claude Code、Codex CLI、ZCode、DSH、GitHub Copilot CLI、OpenCode、Gemini CLI、Qwen Code、Goose、
Grok、Kimi Code、Amp、Droid (Factory)、Hermes、Kilo、Codebuff、pi-agent、OpenClaw、Antigravity。
全部直读本地日志/数据库（JSONL 流式解析或 SQLite 只读连接），不 spawn 外部进程，数据目录可用环境变量覆盖。

**9 个固定视图**
总览 / 会话 / Agent / 模型 / 项目 / 时间分析 / 成本分析 / 数据与计价 / 设置。时间范围、Agent、模型、
项目四维筛选贯穿所有视图；时间分析含小时热力图与星期分布；CSV 导出。

**诚实的成本口径**（这是产品的信任锚）

- 日志自带 `costUSD` 直接采用，不重算；
- 缺价模型显示「未知」，**不折零、不混入合计**，绝不假装精确；
- 服务档位（`fast` / `flex`）按倍率表计价，与 `ccusage` 20.x 对齐；
- 逐日 × 逐模型的 tokens 五分量与 `npx ccusage@20.0.29` **精确一致**，成本容差 ≤0.5%（本机实测逐分钱一致）。

**三级定价回退**
用户覆盖 → models.dev 远程刷新（后台、TTL 24h、永不阻塞 UI）→ 内置价格快照。

**增量采集**
按文件 mtime/大小记账，变更才重扫；全源变更探针 + 零变更轮短路让静止轮零读取零解析；重复运行不产生
重复记录，文件删除后记录随之移除。历史数据常驻内存从百 MB 量级降到 MB 量级。

**托盘常驻**
弹层一眼看今日 tokens / 花费 / 实时速率，成本异常以徽章标出；明暗主题（light / dark / system）跟随系统。

**10 种界面语言**
简繁中文、英、日、韩、葡（BR）、俄、西、德、法，外加跟随系统；数字单位随语种切换（日韩万进制，西文千进制）。

**应用内更新检查**
托盘菜单与设置页「关于」区共享同一状态：静默周检发现新版本后翻标题，点击可一键下载更新包（三个 CN 加速
镜像依次兜底）并在文件管理器中定位。

## 首版前最后一轮加固

- 下载失败分类修正：镜像超时不再被当成"用户取消"而中断整条镜像链；
- 下载完整性校验：`Content-Length` 实际收满 + ZIP 魔数检查，镜像返回限流网页时不再被改名成 `.zip`；
- 设置页跟随后台周检结果（老用户"周检发现新版 → 进设置页下载"这条路径此前按钮是隐藏的）；
- 设置文件并发写不再可能损坏（临时文件名带 Guid + 串行化 + 孤儿文件清理）。

## 已知限制

首版带有若干已知问题，写在 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)——
其中值得先看一眼的两条：

- **读失败会被静默吞掉**：某源日志读不动时界面仍显示正常，可能少算；
- **改过系统时区/夏令时后可能双算**：全量快照行只增不删，建议重建 `tokenmetry.db`。

## 安装

四个 zip，按平台取一个：

| 平台 | 资产 |
|---|---|
| macOS Apple Silicon | `Tokenmetry-0.3.0-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.3.0-osx-x64.zip` |
| Windows x64 | `Tokenmetry-0.3.0-win-x64.zip` |
| Linux x64 | `Tokenmetry-0.3.0-linux-x64.zip` |

- **macOS**：解压得到 `Tokenmetry.app`。应用为 ad-hoc 签名（无 Apple 开发者账号，未公证），首次打开会
  提示"无法验证开发者"。macOS 26 上**右键「打开」已不再能绕过**，走「系统设置 → 隐私与安全性 →
  最下面 → 仍要打开 → 输密码」，或一行命令省掉全部麻烦：`xattr -cr Tokenmetry.app`。
- **Windows**：解压即得单文件 `Tokenmetry.exe`，SmartScreen 会提示「未知发布者」→「更多信息」→「仍要运行」。
- **Linux**：解压后 `chmod +x Tokenmetry && ./Tokenmetry`。

也需要 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) 从源码运行：
`dotnet run --project src/Tokenmetry.App`。

## 数据与隐私

SQLite 只存**聚合事实与配置**，不存 prompt、代码、会话内容；不上传、不登录、不云同步，断网功能完整。
数据留在本机（Windows `%LOCALAPPDATA%\Tokenmetry\`，macOS/Linux 为用户数据目录）。
