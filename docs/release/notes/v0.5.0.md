# Tokenmetry v0.5.0

**分享海报从两个样式扩到五个、对话框全面升级；主题改「画板 × 模式」两维并新增四套画板；外加独立的模型计价器工具。**

## 这一版有什么

**分享海报：五个样式**

- 新增**打卡热力图**：周为列、星期为行的按天格子，token 量映射色阶深浅，空日如实留白（横版）。
- 新增**时段节律**：星期 × 小时热力矩阵，回答「什么时候在用 AI」；粗精度的用量计入 unknown 小注（横版）。
- 新增**里程碑**：Wrapped 式大数字叙事版式，照 HTML 设计稿重排（竖版）。
- 信息卡画布收窄到 900 窄版；样式与时间范围解耦——总览样式在单日范围下自动切小时形态。
- 日间导出的投影改走 `DropShadowEffect`：Avalonia 在 RenderTargetBitmap 上 DPI≠96 时
  `BoxShadow` 会把 DPI 平方乘进后续变换（上游 [#20693](https://github.com/AvaloniaUI/Avalonia/issues/20693)），导出前必须绕开。

**海报对话框**

- **内嵌数据范围筛选**，与主窗口双向同步（关窗保留改动）——海报永远印「当前筛选下的这个视图」。
- **选项即存**：样式、版式、主题、雾化，上次使用即下次默认。
- 预览默认缩放到全貌，Ctrl/⌘ + 滚轮放大、双击复位；页边距开成可调参数。
- 建议文件名固定为保存时刻 `yyyyMMdd-HHmmss`，不再按选项拼接。

**主题：画板 × 模式两维**

- 主题拆成两维：**画板**（整套配色皮肤）× **模式**（日间 / 夜间 / 跟随系统），设置页两个选择器。
- 新增四套画板：**Nord / Dracula / Solarized / Gruvbox**（Nord 与 Dracula 只提供夜间）。
  全部由脚本生成、逐令牌过对比度纪律；旧 settings.json 无新键 = 默认画板，零迁移。

**模型计价器**

- 独立工具：给定 token 量与模型单价（或直接贴 models.dev 数据），就地算一笔账；
  托盘菜单与 macOS Tools 菜单都有入口。
- 模型统计页的未知模型右键直达「补价 / 映射」，不用再翻设置。

**修复**

- ToolTip 失活守卫：应用失活后悬浮 Tip 不再钉死在所有 App 之前。
- 模型统计页整行可右键，不再只认名字字形。
- 弹层「正在工作」横幅的 Agent 归属改增量口径，不再时有时无。
- 总览「今日」趋势图横轴不再显示 1899/1900 日期（[#3](https://github.com/cholf5/tokenmetry/issues/3)）。
- 关于区新增求 Star 文案——觉得好用的话，顺手给个 Star 是对独立开发最实在的支持。

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](docs/release/known-limitations.md)。重点：

- **包都未签名**：Windows 安装器触发 SmartScreen「未知发布者」（→「更多信息」→「仍要运行」）；
  macOS 仍是 ad-hoc 签名，**全新安装**首次打开会被 Gatekeeper 拦一次（应用内更新不触发）。
  macOS 26 已没有「右键 → 打开」捷径，最省事的是终端一行命令（抹掉 quarantine 标，之后双击直接过）：

  ```bash
  xattr -cr /Applications/Tokenmetry.app
  ```

- **便携 zip 与 Linux 包仍有首次解包**（约 20MB 写临时目录）；想避开就用 Windows 安装器或 macOS 版。
- **Linux 版未在真机验证**（CI 有启动冒烟，画面与托盘验不了）。
- macOS 不做 .dmg（已决策）：zip 解压、拖进应用程序目录即可。

## 安装

| 平台 | 资产 |
|---|---|
| Windows x64（推荐） | `Tokenmetry-0.5.0-win-x64-setup.exe` |
| Windows x64（便携） | `Tokenmetry-0.5.0-win-x64.zip` |
| macOS Apple Silicon | `Tokenmetry-0.5.0-osx-arm64.zip` |
| macOS Intel | `Tokenmetry-0.5.0-osx-x64.zip` |
| Linux x64 | `Tokenmetry-0.5.0-linux-x64.zip` |

- **已装 v0.4.0 的用户：应用内一键更新**——主窗横幅 / 设置页「关于」/ 托盘菜单任一处点「立即更新」，
  静默升级后应用自动回来（Windows 安装副本走安装器静默升级，其余平台原子替换、失败自动回滚）。
- 全新安装：下载对应平台的包，Windows 跑安装器（或解压便携 zip），macOS 解压后拖进应用程序目录
  （首次放行命令见上），Linux 解压即用。
